# JavaScript Password Manager

A simple Password Manager built using **HTML, CSS and Vanilla JavaScript**.

## Features

-  Save Website Credentials
-  Store Username / Email
-  Store Passwords
-  Search by Website
-  Delete Password Entries
-  Show / Hide Password

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
